## 研讨课一：SSH 密钥与 GitHub（学生操作）

前置：W8 已会 HTTPS 的 `git add` / `commit` / `push`。

1. 生成本机密钥：`ssh-keygen -t ed25519`（每人自己的，勿共用）。
2. 认文件：
   - **公钥** `id_ed25519.pub`：一行，以 `ssh-ed25519` 开头 → 粘贴到 GitHub。
   - **私钥** `id_ed25519`：多行，`BEGIN OPENSSH PRIVATE KEY` → **绝不提交、截图、发群**。
3. GitHub 添加 SSH key；本机 `ssh -T git@github.com`。
4. `git remote set-url` 改为 `git@...` 再 push。

卡住：`Permission denied` 先看公钥是否整行粘贴；仍要密码则 `git remote -v` 是不是还是 https。

## 项目 B：单调队列 + 优先队列应用（二选一）

### 背景

滑动窗口最大值是算法竞赛的经典问题。单调双端队列通过维护"可能成为最大值的候选"，在 O(n) 时间内解决。优先队列则用于按优先级调度任务。

### 任务

1. **滑动窗口最大值**：数组 `[5, 3, 4, 1, 2]`，窗口大小 `k=3`。
   
   用单调双端队列，写出每一步队列内容的变化：
   
   ```python
   from collections import deque
   
   def max_sliding_window(nums, k):
       dq = deque()
       result = []
       for i, x in enumerate(nums):
           # 移除窗口外的元素
           if dq and dq[0] <= i - k:
               dq.popleft()
           # 保持单调递减
           while dq and nums[dq[-1]] <= x:
               dq.pop()
           dq.append(i)
           if i >= k - 1:
               result.append(nums[dq[0]])
       return result
   ```
