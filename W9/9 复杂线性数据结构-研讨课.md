# HTTPS push vs SSH push

| | HTTPS | SSH |
|:---|:---|:---|
| 远程地址 | `https://github.com/用户/仓库.git` | `git@github.com:用户/仓库.git` |
| 身份证明 | 账号 / Token | **私钥**（本机）对上 **公钥**（GitHub） |
| 课堂体验 | 易卡在登录 | 配好后 `git push` 通常不再问口令 |

W8 的仓库可以继续用；把 `origin` 改成 SSH 地址即可。

# 密钥对是什么？

| 文件（默认名） | 角色 | 能不能给人看 |
|:---|:---|:---|
| `id_ed25519` | **私钥** | **绝不能**发群、贴作业、喂 AI |
| `id_ed25519.pub` | **公钥** | 可以交给 GitHub |

存放：macOS / Linux `~/.ssh/`；Windows `C:\Users\你的用户名\.ssh\`。

# 密钥文件长什么样？（必看）

**公钥**——一整行，可复制到 GitHub：

```text
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJxxxx... user@email
```

**私钥**——多行，只准自己看：

```text
-----BEGIN OPENSSH PRIVATE KEY-----
...
-----END OPENSSH PRIVATE KEY-----
```

| 辨认 | 公钥 `.pub` | 私钥（无后缀） |
|:---|:---|:---|
| 开头 | `ssh-ed25519` | `-----BEGIN OPENSSH PRIVATE KEY-----` |
| 行数 | 通常 **1 行** | **很多行** |

作业/截图/群聊出现 `BEGIN OPENSSH PRIVATE KEY` → 立刻作废并重新 `ssh-keygen`。

# 项目 A：循环队列（二选一）

**背景**：固定大小数组 + 读写指针绕回 → **环形缓冲区（Circular Buffer）**。

**任务**：
1. 补全 `CircularQueue` 的 `enqueue` / `dequeue`
2. `capacity=4`，依次：`enqueue(1), enqueue(2), dequeue(), enqueue(3), enqueue(4), enqueue(5)`（最后一个应失败）——每步画 `front`、`rear`、`count`、数组
3. 用 `count` 区分空/满 vs"牺牲一个空位"，各有什么优劣？

```python
class CircularQueue:
    def __init__(self, capacity=5):
        self.items = [None] * capacity
        self.capacity = capacity
        self.front = self.rear = 0
        self.count = 0
    # 补全 enqueue / dequeue
```

---
# 项目 A：参考答案要点

```python
def enqueue(self, x):
    if self.count == self.capacity:
        return   # 满
    self.items[self.rear] = x
    self.rear = (self.rear + 1) % self.capacity   # 绕回！
    self.count += 1

def dequeue(self):
    if self.count == 0:
        return None
    x = self.items[self.front]
    self.front = (self.front + 1) % self.capacity
    self.count -= 1
    return x
```

**状态追踪（capacity=4）**：
- `enqueue(4)` 后：`rear=0` ← **绕回**（原 rear=3，下一格索引 0）
- `enqueue(5)`：失败（`count == capacity`）

# 项目 B：滑动窗口最大值（二选一 · 1）

数组 `[5, 3, 4, 1, 2]`，窗口 `k=3` → 结果 `[5, 4, 4]`。

**单调双端队列**：存**可能成为最大值的索引**，队头始终是当前窗口最大。

```python
from collections import deque

def max_sliding_window(nums, k):
    dq = deque()
    result = []
    for i, x in enumerate(nums):
        if dq and dq[0] <= i - k:      # 移除窗口外
            dq.popleft()
        while dq and nums[dq[-1]] <= x:  # 维护单调递减
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

---
# 项目 B：逐步追踪（k=3）

| i | x | dq（存索引） | result |
|:---:|:---:|:---|:---|
| 0 | 5 | [0] | [] |
| 1 | 3 | [0, 1] | [] |
| 2 | 4 | [0, 2] | [5] |
| 3 | 1 | [2, 3] | [5, 4] |
| 4 | 2 | [2, 3, 4] | [5, 4, 4] |

**思考**：新元素比老元素大时，老元素为何"永无出头之日"？（窗口内更小且更早过期）

**复杂度 O(n)**：每个索引最多入队、出队各一次。

# 项目 B：优先队列任务调度（二选一 · 2）

5 个任务，优先级 `[3, 1, 4, 1, 5]`——用 `heapq` **从低到高**处理。

**同优先级按到达顺序**：元组 `(priority, sequence, task)`

```python
import heapq

tasks = []
priorities = [3, 1, 4, 1, 5]
for i, p in enumerate(priorities):
    heapq.heappush(tasks, (p, i, f"任务{i}"))

while tasks:
    print(heapq.heappop(tasks))
# (1,1,任务1) (1,3,任务3) (3,0,任务0) (4,2,任务2) (5,4,任务4)
```

**注意**：`heapq` 是**小根堆**；要大根堆 → 存负数。

# 研讨课二收束：典型错误

| 典型错误 | 现象 | 修正 |
|:---|:---|:---|
| 循环队列忘记 `%` | 数组越界 | `rear = (rear + 1) % capacity` |
| 只用 `front==rear` 判空满 | 空满混淆 | 加 `count`，或牺牲一个空位 |
| 单调队列不删过期索引 | 结果含旧窗口最大值 | `dq[0] <= i - k` 时 `popleft` |
| 以为 `heapq` 取最大 | 最小先出 | 小根堆；大根堆存 `-x` |
| 元组不可比较 | TypeError | 确保 `(p, i, name)` 各字段可比较 |

---
# 研讨课二：思维反思

1. **绕回**：环形跑道、钟表 12→1——固定空间反复利用
2. **单调队列 O(n)**：看似双重循环，每元素最多被 `pop` 一次
3. **优先队列 vs 普通队列**：公平排队 vs 重要任务插队（急诊、调度）
